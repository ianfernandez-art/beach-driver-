🎮 Como Jogar
O jogo começa com o desafio: "Duvido você passar do km 5!!!!!".

O Hyundai Creta mantém uma velocidade mínima constante de 100 km/h e não para sozinho.

Seu objetivo é desviar dos outros carros trocando de faixa e gerenciando a aceleração.

Chegando ao km 5.00, você passará por um ponto de controle com diálogo exclusivo e um impulso de velocidade para testar seus reflexos!

🕹️ Controles
📱 No Celular (Toque na Tela)
Setas ⬆️ / ⬇️ (Esquerda): Troca de pista para cima ou para baixo.

Botão FREIO < (Direita): Reduz a velocidade até o limite mínimo de 100 km/h.

Botão ACELERA > (Direita): Acelera o veículo acima de 100 km/h.

💻 No Computador (Teclado)
Seta para Cima (⬆️): Mudar para a faixa de cima.

Seta para Baixo (⬇️): Mudar para a faixa de baixo.

Seta para a Esquerda (⬅️): Frear (mínimo de 100 km/h).

Seta para a Direita (➡️): Acelerar.

Barra de Espaço: Iniciar o jogo / Reiniciar após bater.
